# publish

## Container Variables
- `ADMIN_TOKEN`: Required. Secret token used to authenticate requests to the `/api/sync` route for CRDT writes.
- `BIND_ADDR`: Optional. The address and port to listen on (default: `0.0.0.0:4405`).
- **Volume Mappings:**
  - `/app/config`: Map this directory to inject custom configuration files
  - `/app/data`: Map this directory for persistent data storage
